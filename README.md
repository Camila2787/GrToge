# GrToge

Aplicación Android para llevar las finanzas de una persona o de una pareja.

## Qué hace

- Registra gastos sueltos y gastos fijos por quincena o por mes.
- Calcula el salario quincenal y lo ajusta si hay incapacidades.
- Anota primas, deudas, ahorro y metas con fecha.
- Muestra cuánto queda del mes y qué porcentaje se fue en gastos, ahorro y deudas.

## Hecho con

Java, Android Studio, XML, Material Design y SQLite.

## Cómo abrirlo

1. Clona este repositorio.
2. Ábrelo en Android Studio.
3. Espera a que termine Gradle y pulsa Run.
